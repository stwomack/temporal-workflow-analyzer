US-003 GitHub URL validation
Done: app/repo_url.py exposes parse_github_repo_url(url) returning a frozen RepoRef(owner, repo, clone_url) and raising InvalidRepoUrlError (a ValueError) with a user readable message. Accepts only https://github.com/<owner>/<repo> with optional .git and optional trailing slash; host match is case insensitive, canonical clone URL is https://github.com/<owner>/<repo>.git. Rejects other schemes and hosts, userinfo, ports, query, fragment, whitespace and control chars, non ASCII, extra path segments, leading dashes, dot names, percent encoding, and shell metacharacters (by allowlist regex). 51 tests.
Decisions: owner follows GitHub username rules (alphanumeric and single hyphens, max 39, no leading or trailing hyphen); repo allows alphanumeric, underscore, dot, hyphen, max 100, no leading hyphen. Legacy owner names with consecutive hyphens are rejected, which is acceptable for a demo.

US-004 clone_repo activity
Consulted: temporal-developer skill (Python error-handling, sync-vs-async, testing references) and Temporal Docs MCP (non-retryable ApplicationError, RetryPolicy non_retryable_error_types matching on type). Inspected installed temporalio 1.34.0 ActivityEnvironment and activity.Info signatures directly.
Done: async activity app.activities.clone_repo(CloneRequest) -> CloneResult(clone_path, file_count, size_bytes), both dataclasses. Validates with app.repo_url.parse_github_repo_url (shared validator). Runs git via asyncio.create_subprocess_exec with an argument list: -c core.symlinks=false -c core.hooksPath=/dev/null clone --depth 1 --single-branch --no-tags --no-recurse-submodules -- <url> <dest>, GIT_TERMINAL_PROMPT=0, own process group. Target is SCAN_ROOT/<workflow_id>/repo, with a clone-complete.json marker beside it (outside the repo) recording clone_url and the result; a matching marker returns immediately, otherwise any partial repo dir and stale marker are removed first. Limits: 200 MB total (including .git) and 20000 files (excluding .git); exceeding raises non-retryable RepoTooLarge and deletes the clone. Error types: InvalidRepoUrl and RepoNotFound and InvalidWorkflowId non-retryable; CloneNetworkError, CloneTimeout and CloneFailed retryable. Git hard timeout 150 s, below the 180 s start_to_close in US-008; on timeout or activity cancellation the git process group is killed.
Decisions: async activity with subprocess and asyncio.to_thread for file walks so the event loop is never blocked. Symlinks are checked out as plain files so the agent cannot read files outside the clone through a planted link. File count excludes .git; size includes it because it is real disk use. Workflow ids must match [A-Za-z0-9][A-Za-z0-9._-]* to be used as a directory name.
Unverified: no heartbeats in clone_repo; US-008 sets no heartbeat timeout for it, so a workflow cancel is not delivered to it mid-clone because Temporal delivers activity cancellation through heartbeats; the clone still ends within 150 s. Revisit in US-008 if clean cancellation during clone matters. Error mapping relies on git stderr text, checked against git 2.54.
